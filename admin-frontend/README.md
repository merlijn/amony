# Amony Admin

A separate admin interface for the Amony media server. It is developed and
deployed independently from the main frontend (`/frontend`) and talks to the
existing backend. In production it is served at `admin.<domain>`.

## Stack

Same as the main frontend: TypeScript, React, Vite, React Router, TanStack Query
and an Orval-generated API client.

## Development

```bash
pnpm install
pnpm run generate   # generate the API client from openapi.yaml
pnpm run dev        # http://localhost:5174
```

The dev server proxies `/api` and `/resources` to the backend on
`http://127.0.0.1:8182`.

### Authentication

The admin frontend logs in with a single identity provider, configured at build
time through `VITE_IDENTITY_PROVIDER` (defaults to `admin`). It does not use the
multi-provider `/api/auth/identity-providers` endpoint.

The backend exposes the admin provider via `AMONY_ADMIN_*` environment variables
and it is hidden from the main frontend. Locally the provider points at the Dex
`admin-app` client.

The OAuth redirect URI is derived from the request (the `X-Forwarded-Host` /
`X-Forwarded-Proto` headers set by the reverse proxy, or the `Host` header when
the backend is reached directly), so no public origin needs to be configured.

Because of that, logging in **from the Vite dev server** (`http://localhost:5174`)
requires that origin to be registered with Dex as well. The dev server forwards the
browser's origin via `X-Forwarded-Host` (see `vite.config.ts`), so while developing
just point the redirect URI at the dev origin in `.env`:

```
DEX_AMONY_ADMIN_REDIRECT_URI=http://localhost:5174/api/auth/callback/admin
```

The admin container origin (`http://localhost:8183`) is the compose default.

## OpenAPI spec

`openapi.yaml` is generated by the backend and contains only the auth and admin
endpoints:

```bash
cd ../backend
sbt generateSpec
```

This also regenerates `../frontend/openapi.yaml`.

## Docker

The image builds the SPA and serves it with nginx, proxying `/api` and
`/resources` to the backend (`AMONY_BACKEND`, defaults to `amony-app:8182`).

```bash
docker build -t amony-admin .
```

In `docker-compose.yml` the container runs as the `admin` service and is exposed
on `http://localhost:8183`.
